# Kurtosis-inspired-robust-machine-health-indicators
The Matlab implementation of the robust estimators used in the paper entitled "Kurtosis-inspired robust machine health indicators under non-Gaussian noise environment" by Aleksandra Grzesiek, Daniel Kuzio, Justyna Witulska, Radosław Zimroz, Tomasz Barszcz, and Agnieszka Wyłomańska
